# Screenshots

The main [README](../../README.md) references image files in this folder
that don't exist yet. Drop in real screenshots of the admin UI
(`http://<host>:8080/ui/`) with these exact filenames and the README will
pick them up automatically:

| Filename | What to capture |
| --- | --- |
| `providers.png` | The Providers page with a couple of providers listed (cards showing name, kind, status) |
| `new-provider.png` | The "New provider" modal open, with the template dropdown visible |
| `pools.png` | The Pools page with at least one pool expanded, showing its member providers |
| `settings.png` | The Settings page's "Connect a client" section (base URL + curl example) |

Keep them reasonably small (crop to the relevant panel, not a full desktop
screenshot) so the README stays fast to load.
